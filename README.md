# Hydro Jetting Service

Single-page, SEO-optimized website for **High Pressure Hydro Jetting Sherman Oaks**.

## Files
- `index.html` – main page (luxury dark/gold/aqua theme, animated hero, 1000+ word article, FAQ schema)
- `robots.txt` – crawler rules and sitemap location
- `sitemap.xml` – sitemap with the home page URL
- `README.md` – this file

## Before you publish
1. Replace `https://www.hydrojettingservice.com/` with your real domain in `index.html` (canonical, og:url, JSON-LD), `robots.txt`, and `sitemap.xml`.
2. Upload all files to the site root.
3. Submit `sitemap.xml` in Google Search Console.
